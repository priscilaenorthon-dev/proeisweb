Alternativa manual

Preencher login por bookmarklet

Se preferir fazer o login manualmente, use o assistente abaixo.

Abrir PROEIS Preencher login

Como usar o bookmarklet

  1. Digite seu ID funcional acima.
  2. Arraste o botao "Preencher login" para a barra de favoritos.
  3. Abra o PROEIS pelo botao acima.
  4. Clique no favorito na pagina oficial. Se a pagina recarregar, clique de novo.
  5. Digite o CAPTCHA e a senha manualmente.
