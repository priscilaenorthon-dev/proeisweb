Primeira etapa do login

Preencha o ID funcional, abra o site oficial e use o botao de preenchimento assistido. O CAPTCHA continua sendo resolvido manualmente no proprio site.

Abrir PROEIS Preencher login

Como usar

  1. Digite seu ID funcional nesta tela.
  2. Arraste o botao "Preencher login" para a barra de favoritos.
  3. Abra o PROEIS pelo botao acima.
  4. Clique no favorito quando estiver na pagina oficial. Se a pagina recarregar ao selecionar ID Funcional, clique no favorito de novo.
  5. Digite o CAPTCHA manualmente e avance.
